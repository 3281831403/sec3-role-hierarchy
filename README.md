角色配了一层继承，普通客服账号顺着继承链摸到了管理员权限，审计里看不出是谁给的权利：角色继承必须在声明中显式给出；继承链不得成环，环必须在展开前被发现并拒绝；继承深度必须有上限，超过上限的展开不得继续；权限合并取各角色权限的并集，且结果不得越出角色闭包；角色名比较前必须归一，大小写与首尾空白不得产生两个角色；批量判定时各主体相互独立，一个主体的展开结果不得污染另一个主体。任何主体最终拿到的权限都必须落在其角色闭包内，同一角色连续两次展开必须得到相同结果。
